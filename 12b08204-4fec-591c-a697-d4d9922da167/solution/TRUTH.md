# Ground truth: Argus web backend from Flask and uWSGI to FastAPI and gunicorn

The reference is the upstream migration of the Argus web backend, scylladb/argus pull request #1059, a rebase-merged series whose last commit is 7e0b152a9a7a19e880c10fb98bc5a8dff9ededcc. The agent's tree is 8a0367430a024b78caff70cfb7059807b3e127da, the parent of the series' first commit, squashed to one commit with AGENTS.md, CLAUDE.md, GEMINI.md, opencode.jsonc, .claude, .gemini, .mcp.json, .codegraph and skills/ removed. solve.sh applies reference.patch, the series' net change to that tree with the repairs below.

## Reference repairs

- R1: page routes answer an unhandled error with the original's HTML 500 page rather than the JSON error envelope, which stays on /api/ and /admin/api/ paths; first case GET /storage/picture/<unknown id>
- R2: similar_runs_info answers the original's two HTTP 400 envelopes, Missing run_ids parameter and run_ids must be a list, rather than request validation errors
- R3: the Zeus proxy sends its upstream request from a worker thread rather than blocking the event loop with a synchronous requests call
- R4: three tests return to the original's assertions: the unknown-picture test in test_profile.py (HTTP 500) and both similar_runs_info tests in test_sct_api.py (HTTP 400 and the original's message)
- R5: the dependency declaration takes upstream's own follow-up fix 8e22243: the dev extra names httpx2, without which the application cannot import the Starlette test client it loads at start
- R6: unmatched URLs, wrong methods and bad requests answer the original's HTML 404, 405 and 400 pages on every path, API paths included
- R7: a URL whose route ends with a slash, requested without it, redirects with 308 to the absolute slashed URL with its query kept; a URL requested with a slash its route lacks is a 404
- R8: every redirect carries the original's short HTML page naming its target, as text/html; charset=utf-8
- R9: HEAD answers as GET without a body, and OPTIONS answers 200 with the route's allowed methods
- R10: the session cookie lives for the browser session: HttpOnly, Path=/, with no Max-Age and no SameSite attribute
- R11: admin API, admin pages and impersonation decide roles before login, so an anonymous request is answered Forbidden; the SSH keys route keeps login first
- R12: a login form missing its username or password is answered with the 400 page
- R13: the request metrics keep the original's series: exporter info version 0.23.2, default series for unmatched requests under endpoint None, per-endpoint counters only for matched routes, and none for the metrics endpoint's own requests in the default series
- R14: GET /api/v1/releases reads its all flag as the original did, by the truth of the raw string: empty is false, any other value true
- R15: the SCT nemesis listing keeps the original's service code, which queries with the run id string and so answers a TypeError envelope; the upstream series changed that service-layer code
- R16: URLs match as in the original's URL map: leading slashes are ignored, a URL with repeated slashes inside it redirects with 308 to the merged URL when that URL is served for the request's method, a path parameter is never empty, and the trailing-slash redirect goes only to a URL served for the request's method
- R17: a HEAD request is served by a route that declares HEAD (the test results existence check answers 200 or 404 with no body) and otherwise answers as GET without a body; a response that names no content type is text/html; charset=utf-8
- R18: a single-valued query parameter given more than once takes its first value; the list parameters keep every value
- R19: the profile updates read each field from the query string first and then the form body, first value, an empty value kept
- R20: integer flags (limited, includeNoVersion, force, deleteView, aggregateByIssue) parse as integers, any non-zero integer true, as the original read them
- R21: the pytest results widget with no results and no date window answers the original's IndexError envelope; the upstream fallback to an empty chart (a43dd09) is not kept
- R22: generated links keep slashes inside parameters, percent-encoding only what a URL path segment cannot carry, as the original's URL building did
- R23: a profile picture upload with no file answers the original's 500 page, with no session cookie
- R24: a login or impersonation form that repeats a field uses its first value, as the original read form fields
- R25: OPTIONS requests are redirected to the slashed URL like every other method, and every strict-slash or merged-slash redirect carries the query string exactly as the client sent it
- R26: an unhandled exception on an API route is answered inside the route, so the request metrics count it as the envelope's HTTP 200 and not as an escaped exception; only page routes count escaped exceptions; the metrics endpoint's own refused requests are counted in the default series

## Stated behaviour changes

- C1: API responses no longer carry the Cache-Control headers some api.py endpoints set (upstream commit baa504c); the comparison profile never compares Cache-Control
- C2: two kinds of JSON API request are answered with HTTP 200 and the RequestValidationError envelope, and only the status code, the envelope's status and response.exception are compared for them. Both are defined by the original's own answer: a non-UUID path id that the original refuses with the ValueError of converting it to a UUID (G04 bad-uuid-release-details), and a request without a JSON Content-Type that the original refuses with its Content-Type mismatch exception (G05 json-without-content-type). Every other error keeps the original's answer, compared exactly: the original's own HTTP 400 answers for a missing or mistyped body field (similar_runs_info, F037 and F038), the exceptions its handlers raise while serving (G04's unknown run id, TypeError; G09's submission without the scylla-server package, ValueError; G10's severity filter, AttributeError), and a plan reference that is not a UUID, which the original also looks up by key and answers with DocumentNotFound (G11). Requests the original accepts without a JSON Content-Type stay accepted (G05 proxy-raw-body, G08's comment delete, and G09's heartbeat and finalize; finalize ignores a missing payload). The reference types the path id as a UUID on four routes where the original accepts any string: the two team edit routes (/api/v1/team/{team_id}/edit and /api/v1/team/{team_id}/motd/edit, whose id the original ignores) and the pages /test_run/{run_id} and /test/{test_id}/runs, which the original renders for any id. A non-UUID id there is refused by the reference and accepted by the original; no recording sends one.
